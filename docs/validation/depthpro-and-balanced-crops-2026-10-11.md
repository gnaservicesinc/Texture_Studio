# DepthPro refiner and balanced crops — October 11, 2026

Texture Studio 0.9.15, build 110, adds the separately named **DepthPro Height Refiner**, permits checkpoint comparison with one selected model, and replaces the old multi-corner crop weighting with balanced zoom tiers. See the [refiner contract](../depthpro-height-refiner.md) and [training workflow](../material-training-workflow.md) for the controls and numeric preparation.

## Resulting behavior

- Compare accepts one checked checkpoint with the untrained initialization unchecked, or the initialization alone. Its source requirement still applies. An empty model selection is rejected only when the initialization is also unchecked. Height output can be inspected alone or alongside the dataset's height reference.
- The refiner receives one floating-point DepthPro input channel and predicts one original material-height channel. RGB is used only by the preceding native Core ML DepthPro stage. Training and inference share the recorded inverse-depth contract and require the same upstream model SHA-256. Raw meters and normalized inputs are cached separately; display grayscale is not the numeric contract.
- For each source folder and selected target, native preparation obtains the matching, 2× and 4× published Poly Haven tiers when needed and saves fetched maps into that original folder. Matching fields remain full-sized; 2× fields produce one center crop; 4× fields produce one of four corners or the center; existing larger diffuse fields produce one random crop and may fetch their missing paired target. Preparation does not fetch new diffuse fields above 4×. Imported external folders register new matching tiers without replacing existing source evidence or review choices. Unregistered unrelated provider assets in the same folder do not trigger downloads.
- **Randomize Crops when** offers Never, the start of a new run, and every epoch. Never disables both remembered orientation controls. Progressive flips transform the current paired cache with four equally likely choices. Center spins use the original paired sources with an integer angle from 1 through 179 degrees, then apply the optional flip. A near-native center field without surrounding pixel support skips that spin and keeps its valid cached pair; the history records this outcome. Original sources and immutable prepared dataset files remain unchanged.
- DepthPro flips permute both cached floating-point grids without prediction or renormalization. Newly spun fields receive fresh predictions before training. The native trainer unloads DepthPro between preparation and optimization; epoch preparation time is excluded from the training time limit. Final cache counts include later epochs.

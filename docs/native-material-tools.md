# Native material tools

Texture Studio contains Dataset Studio, Model Training, Checkpoint Compare and Material Review as SwiftUI tools. Open them from the app's Tools menu. They use the same native services and model selections as the main application.

Dataset Studio opens existing source folders, adds images or material subfolders, edits image tags, curates samples and displays exact native crops. An optional New Source Folder action creates an empty folder. The files inside the selected folder determine dataset membership, including unassigned images and maps that cannot train at the selected size. An old `dataset.json` does not replace that inventory or authorize references outside the folder. Originals retain their bytes, dimensions and precision.

Loom Room groups current materials by their saved tags. The selected category and map type determine the training pairs; selecting an image for inspection does not limit training to that image's folder. Browsing originals preserves the training category, map and explicit crop size. Category inventories and training crops are disposable projections rebuilt from the source folder, rather than separate editable membership lists. Source-folder setup does not require downloading a fixed set of resolution tiers. See the [training workflow](material-training-workflow.md).

Model Training evaluates and refines the pinned PBRnxt material mapping or trains a compact native model with Apple MPSGraph on Metal. Choose **Compact scalar** for height or roughness (one output channel), or **Compact normals** (three output channels). Each of these RGB compact models trains its entire backbone and target head from scratch, keeps RGB diffuse input, and needs no base download. It preserves the selected grid and keeps Float32 inference, gradients and optimizer state. Checkpoints use a data-only safetensors format. Package export includes configuration, SHA-256 inventory and upstream notices. An RGB compact checkpoint or complete fused PBRnxt checkpoint runs without a separately installed base. The separate **DepthPro Height Refiner** has an upstream DepthPro dependency and is described below. See the [training workflow](material-training-workflow.md) for setup and evaluation limits.

Checkpoint Compare presents each model separately, with its name first and map type and training step below. Choose the shared test photo and models, then inspect their outputs side by side. Material Review provides linked views, numeric display modes and crop reconstruction. Review transformations operate on exact decoded PNG integer samples. Original maps remain untouched; any model-input transfer or declared normal convention is recorded separately.

Settings choose a working folder and model weights. **Locate Material Model…** loads native safetensors files or exported folders; developer Core ML packages use their own action. Hugging Face authentication recognizes an existing `hf auth login`, environment credentials or an optional token stored in Apple Keychain. Native URLSession services handle accounts, catalogs, verified downloads and LFS uploads. Uploads contain model packages only. Source photos and dataset maps are excluded.

File → Export Original Auxiliary Data exports all ImageIO-exposed auxiliary types from every image index into a new directory. It saves untouched data buffers, stride/layout descriptions and metadata; supported scalar buffers also receive exact NPY files. It preserves the original photo and does not gamma-correct, normalize or tone-map these scientific arrays. Apple ImageIO does not enumerate arbitrary private HEIF items, so the report states that coverage limit.

## DepthPro Height Refiner

The separate **DepthPro Height Refiner** family consumes one cached normalized inverse-depth channel and predicts one original material-height channel. A dedicated native Core ML adapter supplies DepthPro's RGB image and required `originalWidth` input; the large model runs during input preparation, and MPSGraph trains the small refiner from the cached Float32 pairs. Training and inference use the same full-field preparation, paired grid and exact DepthPro model identity. The complete small refiner exports separately from its required upstream DepthPro weights. This is a research experiment with unresolved commercial upstream-model rights; see its [numeric contract and evaluation limits](depthpro-height-refiner.md).

Checkpoint Compare can run a single checkpoint with its optional initialization unchecked, then show that output alone or with an available original-height reference. The optional initialization can also run without checked checkpoints.

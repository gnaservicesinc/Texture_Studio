# Native material tools

Texture Studio contains Dataset Studio, Model Training, Checkpoint Compare and Material Review as SwiftUI tools. Open them from the app's Tools menu. They use the same native services and model selections as the main application.

Dataset Studio creates and edits current material datasets, scans/imports folders, curates samples, prepares exact native crops and removes owned temporary preparation data. It preserves original map bytes and records hashes, bit depth, original dimensions, crop rectangles and split ancestry. Dataset removal validates the selected dataset and its deletion scope again before moving owned data to Trash. Unsupported source formats are rejected explicitly rather than converted through a display pipeline.

Training a selected source folder includes its eligible resolution tiers. A verified Poly Haven original permits an attempt to obtain missing paired tiers during preparation, even when the current dataset has no matching target or larger tier registered. Preparation reports the actual provider or file-verification failure if that pair cannot be obtained. Original dimensions must agree with the provider's nominal resolution; a filename alone does not enable recovery. See the [crop tier rules](material-training-workflow.md).

Model Training evaluates and refines the pinned PBRnxt material mapping or trains a compact native prototype with Apple MPSGraph on Metal. Choose **Compact scalar** for height or roughness (one output channel), or **Compact normals** (three output channels). Each of these RGB compact models trains its entire backbone and target head from scratch, keeps RGB diffuse input, and needs no base download. It preserves the selected grid and keeps Float32 inference, gradients and optimizer state. Checkpoints use a data-only safetensors format. Package export includes configuration, SHA-256 inventory and upstream notices. An RGB compact checkpoint or complete fused PBRnxt checkpoint runs without a separately installed base. The separate **DepthPro Height Refiner** has an upstream DepthPro dependency and is described below. See the [training workflow](material-training-workflow.md) for setup and evaluation limits.

Checkpoint Compare and Material Review show reference, base and checkpoint maps with linked views, numeric display modes and crop reconstruction. Review transformations operate on exact decoded PNG integer samples. Original maps remain untouched; any model-input transfer or declared normal convention is recorded separately.

Settings choose a working folder and model weights. **Locate Material Model…** loads native safetensors files or exported folders; developer Core ML packages use their own action. Hugging Face authentication recognizes an existing `hf auth login`, environment credentials or an optional token stored in Apple Keychain. Native URLSession services handle accounts, catalogs, verified downloads and LFS uploads. Uploads contain model packages only. Source photos and dataset maps are excluded.

File → Export Original Auxiliary Data exports all ImageIO-exposed auxiliary types from every image index into a new directory. It saves untouched data buffers, stride/layout descriptions and metadata; supported scalar buffers also receive exact NPY files. It preserves the original photo and does not gamma-correct, normalize or tone-map these scientific arrays. Apple ImageIO does not enumerate arbitrary private HEIF items, so the report states that coverage limit.

## DepthPro Height Refiner

The separate **DepthPro Height Refiner** family consumes one cached normalized inverse-depth channel and predicts one original material-height channel. A dedicated native Core ML adapter supplies DepthPro's RGB image and required `originalWidth` input; the large model runs during input preparation, and MPSGraph trains the small refiner from the cached Float32 pairs. Training and inference use the same full-field preparation, paired grid and exact DepthPro model identity. The complete small refiner exports separately from its required upstream DepthPro weights. This is a research experiment with unresolved commercial upstream-model rights; see its [numeric contract and evaluation limits](depthpro-height-refiner.md).

Checkpoint Compare can run a single checkpoint with its optional initialization unchecked, then show that output alone or with an available original-height reference. The optional initialization can also run without checked checkpoints.

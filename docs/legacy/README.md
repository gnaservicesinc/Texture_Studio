# Archived Qt studio documentation

These files describe the former IPDE Studio, Extractor, Dataset Studio, RAFT
Studio, Photo Studio, and Raw Studio Qt applications. Those applications and
build paths were retired when the repository adopted the standalone SwiftUI
Texture Studio. Commands, menus, screenshots, and system requirements in this
archive are historical.

The Python extraction, dataset, and research modules remain available for
existing workflows. Existing datasets, model checkpoints, and exports were not
moved or deleted by the application migration. Follow the current repository
README and `docs/releasing.md` for the native app.

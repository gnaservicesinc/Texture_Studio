# Texture Studio documentation

- [Texture editor](texture-studio.md): import, photo correction, map inspection and Blender export.
- [Release packaging](releasing.md): build and package the macOS application.
- [Texture Loom package contract](texture-loom-package-contract.md): the new shared model and adapter format.

Full model training and classifier development belong to [Loom Factory](https://github.com/gnaservicesinc/LoomFactory). LoRA training belongs to [Loom Workshop](https://github.com/gnaservicesinc/LoomWorkshop).

The `validation` directory records historical measurements of the retired implementation and does not describe the current products.
Machine-specific paths in published validation notes use `/path/to/workspace`
and `/path/to/user` placeholders; recorded measurements and hashes are preserved.
